# L'ORACLE DU CLAVIER de `browse` — ce que chaque touche fait VRAIMENT, par contexte.
#
# Engendré par `browse::state::keyboard`. Ne pas éditer à la main : lire le diff, le
# vouloir, puis NAMFOOP_UPDATE_KEYBOARD=1 cargo test -p namfoop --bin namfoop keyboard
#
# « inertes » = les touches qui ne changent RIEN dans ce contexte : ni action, ni message,
# ni le moindre champ d'état. Une touche annoncée par la barre du bas qui apparaît là est
# un mensonge : la jointure avec la table la refuse.
