namfoop · l'accordeur silencieux

Maquette de docs/design/accordeur.md. Clique dans le terminal, puis joue au clavier ou avec la barre de touches. À droite, gratte une corde, envoie du MIDI et regarde ce qui sort vers la façade et les in-ears. Le set, les sons et les textes sont fictifs.

Ce qui sort

      

    

    

      
Décidé le 23/11

      
    
        
  1. La place. Sur scène, l'accordeur prend la colonne du prompteur, la set list reste à gauche et le morceau suivant sous l'accordeur. Ailleurs, une fenêtre. Le très grand, lisible de loin, viendra avec l'écran de scène.
    2. 
        
  2. La corde qui s'éteint. La dernière note reste grisée 2 s, puis « joue une corde ».
    3. 
        
  3. L'aiguille. Vert à ±3 cents, vert atténué jusqu'à ±10, blanc au-delà ; lissée sur 250 ms. La flèche dit le geste (« monte », « descends »).
    4. 
        
  4. Les couleurs. Le violet UV ne marque que l'état coupé, l'écran derrière passe en gris ; au retour, « son rendu » en vert 2 s.
