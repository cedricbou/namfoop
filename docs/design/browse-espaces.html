    3. 
        
  3. 2 : Chaîne. Va sur un bloc nam, Entrée : la liste s'ouvre dessous, ↑↓ essaie dans la chaîne, Échap remet l'ancien.
    4. 
        
  4. Dans la liste : c bascule entre l'actuel et l'essai, o isole l'ampli et son baffle, r coupe les effets.
    5. 
        
  5. Taille 160 × 50 : le panneau Spectre apparaît, dans la Bibliothèque comme dans la liste de la Chaîne (référence : le modèle actuel).
    6. 
        
  6. a puis nam : le nouveau bloc s'ouvre tout de suite sur la liste.
    7. 
        
  7. Chaîne vide, Bibliothèque, Entrée : le parcours « j'ouvre, je choisis un son ».
