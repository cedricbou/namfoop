namfoop · le mode Set : la set list de concert

Maquette de docs/design/set.md. Clique dans le terminal puis joue au clavier (ou avec la barre de touches). Rien n'est joué : la ligne ♪ dit ce qu'on entendrait. Le pédalier envoie PgDn / PgUp (son suivant / précédent) et → / ← (morceau suivant / précédent, touches réglables). Presets, morceaux et textes sont fictifs.

Décidé le 15/11

      
    
        
  1. MIDI à la Fractal : PC n = le morceau (n° unique dans le set), CC 34 valeur k = son k+1 du morceau joué.
    2. 
        
  2. Métrique dans le ChordPro ({time}, {tempo} successifs) ; BPM toujours à la noire, comme Live.
    3. 
        
  3. Bande de battue : temps 1 en jaune, compte à rebours avant un changement de son.
    4. 
      

      
À valider

      
    
        
  1. Pas de bouclage dans un set : PgDn sur le dernier son ne revient pas au premier.
    2. 
        
  2. Le morceau impose son tempo à tous ses sons ; le volume, lui, se règle son par son.
    3. 
        
  3. Dans la Chaîne, S modifie le preset partout où il sert (le set le rappelle).
    4. 
        
  4. En défilement, la position suit le temps ; à l'arrêt, elle suit le son.
    5.
