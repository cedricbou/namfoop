Maquette : le prompteur en grille

L'espace Set de namfoop browse lit un fichier ChordPro écrit en grilles d'accords : la mesure jouée s'allume, le son de chaque section se choisit dans le set, un morceau s'ajoute à partir de son prompteur. Cliquer dans l'écran, puis jouer au clavier ; les boutons font la même chose.

Le parcours

    La maquette lit réellement le fichier affiché à côté : ses sections, ses mesures et ses repères en sortent.

    Le fichier lu : library/sets/prompts/le-phare.cho
